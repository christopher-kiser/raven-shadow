Commercial-use licensing is screened from upstream declarations, not legal certification. MIT and Apache-2.0 allow commercial uses subject to their terms; preserve license/attribution and audit separately licensed model/data/enterprise content before incorporation. No third-party component is adopted in this campaign. Benchmark decision: reuse existing Store's hash-checked reads and the owner-supplied independent synthetic Shadow oracle; validate the small adapter against adversarial cases. Model quality, memory and latency comparisons remain NOT RUN.

Future dataset work: the model cards link training/evaluation datasets, but no external dataset is approved for ingestion or redistribution. Start with owned synthetic cases and held-out outcomes. A separate license/data-governance review must precede any dataset trial.
